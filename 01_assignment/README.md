# 🐣 C Programming Assignments

C언어의 기초 문법과 논리적 사고력을 기르기 위한 과제 및 실습 코드 모음입니다.

---

## 📋 주요 학습 내용

### 1) 입출력 및 연산 (Basic I/O & Operations)
- **1-3.c**: `printf`를 활용한 이름, 주소, 나이 등 기본 신상 정보 출력 실습
- **1-4.c**: `scanf`로 학번과 국어/영어 성적을 입력받아 출력하는 기초 정보 처리 실습
- **2-2.c**: 중간고사·기말고사 점수를 입력받아 평균을 계산하고 출력
- **2-4.c**: 입력한 개월 수를 시간/분/초 단위로 환산하는 시간 변환 프로그램
- **2-7.c**: 키를 입력받아 `(height - 100) × 0.9` 공식을 적용해 결과를 산출하는 연산 실습

### 2) 제어문 (Control Flow)
- **3-2.c**: `if-else`로 두 숫자의 크기를 비교하고 결과를 출력
- **3-3.c**: 국어/영어/수학 점수를 입력받아 평균 및 개별 점수 기준으로 합격/불합격 판정
- **3-5.c**: `if-else if`로 점수 구간을 나눠 A~F 학점을 계산하는 학점 계산기
- **4-2.c**: `for` 반복문으로 매달 일정 금액을 저축했을 때 30년 누적 금액 계산
- **4-6.c**: 중첩 반복문과 `scanf`를 활용해 입력한 문자(ASCII 값)만큼 `+` 패턴 출력
- **4-9.c**: 반복문 내부에서 `continue`로 1~100 사이 짝수만 선별 출력

### 3) 배열과 문자열 (Arrays & Strings)
- **5_1-1.c**: 10개 점수를 배열에 저장하고 합계/평균 계산
- **5_1-3.c**: 배열 요소 비교로 최댓값을 찾고 내림차순 재배치(정렬 로직 기초)
- **5_1-4.c**: 10개 정수의 최댓값(Max)과 최솟값(Min)을 동시에 탐색
- **5_2-2.c**, **5_2-2-strcpy.c**: 문자열 공백 제거 후 새 문자열로 복사(`strcpy` 활용 버전 포함)
- **5_2-3.c**, **5_2-3-new.c**: `ctype.h`의 `isupper`, `islower` 등을 활용해 대/소문자 상호 변환
- **5_2-4.c**: 문자열 명령어 입력(더하기/빼기 등)에 따라 사칙연산을 수행하는 계산기 인터페이스
- **6-5.c**, **6-5-scanf.c**: 포인터 연산으로 입력된 단어/문자열을 역순으로 뒤집어 출력

### 4) 포인터와 구조체 (Pointers & Structures)
- **6-7.c**: `argc`, `argv`로 전달된 값을 `atoi`로 변환해 16진수 출력 또는 합계 계산
- **7-3.c**: 사용자 정의 함수로 점수를 학점 문자로 변환(기능 분화 실습)
- **7-6.c**: 포인터 매개변수로 원본 값을 직접 변경하는 Call by Reference 합계 계산
- **7-9.c**: `argv`로 받은 다수 문자열을 역순 처리하며 각각 대/소문자를 변환해 출력
- **8_1-1.c**: 구조체 배열로 학생(이름/번호/성적) 정보를 통합 관리하고 평균 산출

### 5) 파일 입출력 기초 (File Basics)
- **9-2.c**, **9-2-safe.c**: 파일에서 특정 단어 존재 여부를 검색(파일 오픈 예외 처리 포함)
- **9-3.c**: `fscanf`로 파일 내용을 문자 단위로 읽어 화면에 재현하는 출력 실습
- **9-4.c**: 원본 파일을 읽고 대상 파일에 그대로 복사하는 파일 복사 기능 구현

### 6) 연결 리스트 기초 (Introduction to Linked List)
- **10_2-3.c**: 단일 연결 리스트(Singly Linked List) 삽입(insert) 및 검색(find) 기초 구현
- **11-1.c**: 이중 연결 리스트(Doubly Linked List)에서 노드 추가/삭제 실습
- **11-2.c**: 연결 리스트 데이터를 파일로 저장(save)하거나 파일에서 읽어 초기화(initialize)하는 영속성 실습

### 7) 비트 연산 (Bitwise Operations)
- **8_2-2.c**: 비트 시프트 연산(`<<`, `>>`) 결과를 확인하는 실습

---

## 🚀 실행 방법 (예시)

```bash
# 컴파일
gcc 3-2.c -o 3-2

# 실행
./3-2
```

> 파일명에 따라 컴파일 대상(`.c`)과 실행 파일명(`-o`)만 바꿔서 실행하면 됩니다.
