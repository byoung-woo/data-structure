# 🔧 Pointers & String Algorithms (Middle Term)

포인터 연산과 메모리 주소 제어의 기초를 다지고, C언어 표준 라이브러리 함수들을 직접 포인터로 구현하며 컴퓨터의 메모리 관리 원리를 학습한 과정입니다.

---

## 🔍 주요 학습 및 실습 내용

### 1) 문자열 라이브러리 직접 구현 (Custom String.h)
표준 라이브러리(`string.h`)를 사용하지 않고, **포인터만**을 사용하여 핵심 문자열 함수를 직접 구현함으로써 문자열의 끝(`'\0'`) 처리와 메모리 참조 원리를 이해했습니다.

- **string.c**: 문자열 길이 계산 `myStrlen` 구현  
- **strcpy.c**: 포인터 증감 연산 기반 문자열 복사 `myStrcpy` 구현  
- **strcat.c**: 두 문자열 결합 `myStrcat` 구현  
- **strcmp.c**: ASCII 값 비교 기반 문자열 비교 `myStrcmp` 구현  

---

### 2) 포인터 기반 문자열 조작 알고리즘
배열 인덱스 대신 **포인터 주소 연산**을 직접 활용하여 효율적인 메모리 조작 알고리즘을 실습했습니다.

- **reverse.c**: `left`, `right` 포인터로 문자열을 제자리(In-place)에서 뒤집기  
- **deletechar.c**: 문자열 내 특정 문자를 찾아 삭제하고 나머지 데이터를 앞으로 당기기  
- **findchar.c**: 특정 문자의 위치(index)를 탐색하여 반환하는 함수  
- **changechar.c**: 특정 인덱스의 문자를 안전하게 변경하는 로직  
- **argc.c**: `argc`, `argv`를 활용한 커맨드 라인 프로그램 제어  

---

### 3) 연도별 기출 문제 풀이 (Exam Solutions)
중간고사 기출 문제를 통해 수학적 사고력과 복합적인 문자열 처리 능력을 훈련했습니다.

#### ✅ 수학 및 기본 로직
- **2022_1.c**: 소수 판별 알고리즘  
- **2019_1.c**, **2020_1.c**, **2021_1.c**: 특정 범위 내 짝수/배수 등 조건부 수열의 합  
- **2019_2.c**: 과락/평균 등 여러 조건을 만족하는지 판별하는 `verify` 함수 구현  

#### ✅ 고급 문자열 조작
- **2020_2.c**, **2020_2_1.c**: 문자열 내 특정 문자 빈도수(등장 횟수) 측정  
- **2021_3.c**: 문자열의 특정 위치에 새 문자열 삽입  
- **2022_3.c**: 인덱스 `n`부터 `m`개의 문자 삭제(부분 문자열 삭제)  
- **2020_3.c**, **2020_3_1.c**: 특정 문자 세트(예: `"lo"`, `"H"`)에 포함된 문자 전부 제거  
- **2019_3.c**, **2019_3_2.c**, **2021_4.c**: 문자열 뒤집기/홀수·짝수 인덱스만 추출 등 선택적 출력  

---

## 🚀 실행 방법 (예시)

```bash
# 컴파일
gcc reverse.c -o reverse

# 실행
./reverse
```

> 파일명에 따라 컴파일 대상(`.c`)과 실행 파일명(`-o`)만 바꿔서 실행하면 됩니다.
