# 📚 Data Structures & Algorithms Lab (C Language)

이 저장소는 C언어를 기반으로 한 **자료구조 및 알고리즘 실습 코드**를 포함하고 있습니다.
기초적인 C 문법부터 포인터, 문자열 처리, 그리고 연결 리스트(Linked List)와 파일 입출력까지 단계별 학습 내용이 정리되어 있습니다.

---

## 📅 Project Information

진행 시기: 2학년 1학기 (사물인터넷 수업)

날짜: 2023.03 ~ 2023.06

---

## 📂 디렉토리 구조 (Directory Structure)

| 폴더명 | 설명 | 주요 키워드 |
| :--- | :--- | :--- |
| **`assignment/`** | C언어 기초 문법 및 과제 | `scanf`, `printf`, `loop`, `struct`, `array` |
| **`middle/`** | 중간고사 대비 및 포인터 실습 | `pointer`, `string manipulation`, `custom string.h` |
| **`final/`** | 기말고사 대비 및 자료구조 심화 | `Linked List`, `Double Linked List`, `File I/O`, `malloc` |
