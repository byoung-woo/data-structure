# 🐣 C Programming Assignments

C언어의 기초 문법과 논리적 사고력을 기르기 위한 과제 및 실습 코드 모음입니다.

## 📋 주요 학습 내용

### 1. 입출력 및 연산 (Basic I/O & Operations)
- **`1-3.c`, `2-2.c`, `2-7.c`**: `printf`, `scanf`를 활용한 기본적인 데이터 입출력 및 산술 연산.
- **`2-4.c`**: 시간 환산 프로그램 (개월 수 -> 시/분/초 변환).

### 2. 제어문 (Control Flow)
- **`3-3.c`, `3-5.c`**: `if-else`문을 활용한 성적 처리 및 학점 계산기.
- **`4-2.c`**: 반복문(`for`)을 이용한 저축 금액 누적 계산.
- **`4-6.c`, `4-9.c`**: 중첩 반복문을 이용한 패턴 출력 및 조건부 출력.

### 3. 배열과 문자열 (Arrays & Strings)
- **`5_1-1.c` ~ `5_1-4.c`**: 배열의 최댓값/최솟값 찾기, 정렬 로직 기초.
- **`5_2-2.c`, `5_2-3.c`**: 문자열 내 공백 제거, 대소문자 변환(`ctype.h`).

### 4. 포인터와 구조체 (Pointers & Structures)
- **`7-6.c`**: 포인터를 이용한 `Call by Reference` 합계 계산.
- **`8_1-1.c`**: 구조체(`struct`)를 활용한 학생 성적 관리 시스템.

### 5. 파일 입출력 기초 (File Basics)
- **`9-2.c`**: 파일을 열어 특정 문자열이 존재하는지 검색하는 프로그램.
